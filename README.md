🚀 AI/ML Internship Projects Portfolio

This repository contains a collection of 10 machine learning and deep learning projects developed during my internship. These projects cover various real-world domains such as healthcare, finance, computer vision, and prediction systems.

📌 Projects Overview
1. 🤟 ASL Detection
Built a model to recognize American Sign Language alphabets
Uses computer vision techniques for gesture recognition
Helps bridge communication gaps for hearing-impaired individuals
2. 🐾 Animal Classification
Image classification model to identify different animals
Uses deep learning (CNN)
Applications in wildlife monitoring and research
3. 🌲 Forest Cover Prediction
Predicts forest cover types using environmental features
Based on classification algorithms
Useful for ecological and geographical analysis
4. 💳 Fraud Detection
Detects fraudulent financial transactions
Uses classification models and imbalance handling techniques
Helps in improving financial security systems
5. ❤️ Heart Disease Prediction
Predicts the likelihood of heart disease
Based on medical dataset features
Useful in early diagnosis and healthcare analytics
6. 🧬 Liver Cirrhosis Stage Prediction
Predicts stages of liver disease progression
Helps in medical decision-making
Uses classification models
7. 🫁 Lung Cancer Prediction
Predicts lung cancer presence using medical attributes
Supports early detection and risk assessment
8. 📱 Mobile Price Prediction
Predicts mobile phone prices based on specifications
Uses regression techniques
Helps in pricing analysis and market insights
9. 🧠 Thyroid Cancer Prediction
Predicts thyroid disease/cancer using medical data
Classification-based approach
10. 🚗 Vehicle Price Prediction
Predicts vehicle prices based on features like mileage, age, etc.
Uses regression models
Useful for resale and pricing platforms
